Why MathMate

传统搜题工具，解决不了真正的学习

Where traditional solvers stop, real learning begins.

面向 12-22 岁数学学习者的四个核心痛点

🔍

拍题只给答案，不讲思路

市面拍照搜题多为题库匹配，只输出固定解析；遇到未收录题目完全无能为力。

📐

几何题目难以可视化

静态图片无法展示动点轨迹、切线变化，学生难以建立空间直觉。

🔀

学习工具分散

计算器、画图、搜题、笔记来回切换，学习流程被反复打断。

🎯

缺乏个性化辅导

不同年级、不同水平需要不同深度的讲解，传统产品千人一面。

Core Pipeline

三步智能解题流程

A three-step intelligent solving pipeline.

拍照上传后，AI 流水线自动完成从识别到可视化的完整流程

01

OCR 智能识别

火山引擎多模态模型将图片识别为 Markdown + LaTeX，支持手写体与印刷体。

02

AI 分步求解

DeepSeek 大模型深度推理，生成清晰分步解析，覆盖小学到大学各难度。

03

几何可视化

AI 自动生成几何 JSON → 自研 Canvas 引擎渲染可交互图形，支持动点与轨迹。

02

交互式几何可视化

自研 Flutter 原生渲染引擎，AI 驱动动态图形

GEOMETRY PAINTER · LIVE

核心创新：AI 自动从题目文本抽取几何参数并生成 JSON，自研 GeometryPainter 引擎（纯 Dart Canvas）实时渲染可交互图形。支持点、线、圆、椭圆、双曲线、抛物线、动点轨迹动画与滑块拖拽。

自研引擎 60fps 原生渲染 动点动画 零 WebView 依赖
06

AI 对话助手

统一流式服务，连续追问数学思路

升级对话首页、消息流与统一流式服务，可在 DeepSeek、Qwen 和火山 Ark 模型之间按任务切换。围绕一道题连续追问条件、公式来源和替代解法，通过 Markdown 与 LaTeX 阅读结构化回答；历史会话支持快速检索。

流式响应 多模型路由 LaTeX 渲染 会话历史
07

自由组卷与考试报告

从选题到答题、评分与复盘的完整链路

在练习工作区按知识板块、难度、题型和题量创建试卷，支持单选、多选、填空与解答题，题目、选项和解析均使用 LaTeX 公式渲染。提交后由规则与 AI 协同评分，考试报告更新计算、逻辑推理、空间想象、抽象思维、应用与数学建模六维画像，覆盖大学阶段能力评估。

自由组卷 多题型答题 自动评分 六维能力雷达
08

个人资料库 + Awesome Math

自己的学习材料与开放数学资源分区管理

在「我的资料」与「资源库」之间切换：前者支持上传课件、真题、图片与音频并由 AI 分类，后者提供 Awesome Math 外链索引，可按学段、资源类型、数学分类与关键词筛选，让个人材料与开放资源分区沉淀。

资料上传 OCR 解析 AI 分类 开放资源索引
